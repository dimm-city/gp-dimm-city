Character set

Caps only: lowercase keys map to the same letters. C, R, E, A, T, U, P, N and K are traced from the source; every other glyph is built from pieces of those.

Swash alternates

The logo's tall C and long-legged K are kept as alternates. Turn them on with font-feature-settings: "swsh" (or "ss01").

Use it

@font-face {
  font-family: 'Creaturepunk';
  src: url('fonts/creaturepunk/Creaturepunk.woff2') format('woff2'),
       url('fonts/creaturepunk/Creaturepunk.ttf') format('truetype');
}
.logo {
  font-family: 'Creaturepunk';
  font-feature-settings: "swsh";        /* tall C, long K */
  color: #ffc700;
  -webkit-text-stroke: .1em #111;       /* the black outline */
  paint-order: stroke fill;             /* keep the stroke behind the fill */
}

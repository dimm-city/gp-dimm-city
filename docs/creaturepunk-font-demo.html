Edit glyphs

Drag points to reshape a glyph and set its side bearings; everything on this page redraws with the edit. Download the result and replace fonts/creaturepunk/Creaturepunk.ttf with it. Only outlines and spacing change: names, licence, swash features and line metrics are kept as they are.

Open the font to edit it.

Click a point to select it, Shift-click to add to the selection, drag on empty space to box-select. Drag or use the arrow keys to move the selection (Shift: 10 units). Ctrl/⌘-Z undoes.

Character set

Caps only: lowercase keys map to the same letters. R, E, A, T, P, N and K are traced from the source, and C and U are traced then reworked so they read in running text; every other glyph is built from pieces of those.

Swash alternates

The logo's own C, U and K (the tall C, the short-stemmed U, the long-legged K) are kept as alternates. Turn them on with font-feature-settings: "swsh" (or "ss01").

Use it

@font-face {
  font-family: 'Creaturepunk';
  src: url('fonts/creaturepunk/Creaturepunk.ttf') format('truetype');
}
.logo {
  font-family: 'Creaturepunk';
  font-feature-settings: "swsh";        /* the logo's C, U and K */
  color: #ffc700;
  -webkit-text-stroke: .1em #111;       /* the black outline */
  paint-order: stroke fill;             /* keep the stroke behind the fill */
}

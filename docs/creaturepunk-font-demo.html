Drag points to reshape a glyph and set its side bearings; everything on this page redraws with the edit. Download the result and replace fonts/creaturepunk/Creaturepunk.ttf with it. Only outlines and spacing change: names, licence and line metrics are kept as they are.

Open the font to edit it.

Click a point to select it, Shift-click to add to the selection, drag on empty space to box-select. Drag or use the arrow keys to move the selection (Shift: 10 units). Ctrl/⌘-Z undoes.

Character set

Caps only: lowercase keys map to the same letters. Every glyph is a feral brush scrawl: talon-hooked stroke ends, spiked stems, fangs under the bars, and claw rakes, bite marks and drips on some of them.

# Neon print proof {.np-title}

<p class="np-lede">Order this page as a DriveThruRPG print proof before any neon reaches the package. Every swatch is flat, opaque vector on an ink plate (--ink): a 1.2pt core (25% of the tube into white), a 3pt tube, a 6pt and a 9pt ring. Check: does it read as lit? Does the core fringe? Do the rings stay apart? CMYK is the tube's, through CGATS21_CRPC1.</p>
